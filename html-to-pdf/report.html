1. Introduction

1.1 Project Objective

5alasly (an Arabic term meaning "Consider it done") is a hyper-local service coordination platform. Our mission is to transform how communities interact by providing a high-trust, low-friction environment for task delegation and skill sharing.

In a world where specialized help is often just a neighbor away, 5alasly provides the digital bridge. Whether it's emergency plumbing, physics tutoring, or moving assistance, the platform ensures that the right "helper" meets the right "client" in seconds.

1.2 Problem Domain

Fragmentation

Local services are scattered across social media or physical ads, making them hard to verify.

Lack of Trust

Hiring strangers requires robust verification and rating systems.

Communication Barriers

Real-time coordination is often lost in external messaging apps.

Invisibility

Talented individuals have no way to reach immediate neighbors.

1.3 Target Audience

  • Local Homeowners: Seeking quick, reliable repairs or assistance.
  • Students: Looking for tutoring or offering skills for income.
  • Freelancers: Offering digital or physical services locally.
  • Active Seniors: Contributing specialized knowledge or assistance.

2. Core Features: Dashboard & Discovery

2.1 The Intelligent Home Dashboard

The Dashboard acts as the user's primary "Cockpit". It synthesizes complex real-time data into digestible metrics and provides immediate access to the community exchange.

Key Dashboard Components:

  1. Metric Strips: Real-time counters for tasks, engagement, and reputation.
  2. Search-to-Filter Engine: Contextual search bar that updates as you type.
  3. Category Quick-Buttons: One-tap filtering for specific domains.

2.2 Search & Discovery Dynamics

The search functionality is a discovery tool that prioritizes results based on proximity and urgency.

Searching for "Cleaning" isolates relevant requests while maintaining dashboard context.

5. Technical Architecture

5.1 Modern Frontend Stack

Built on Angular v21, utilizing the latest reactive patterns.

  • Angular Signals: Signal-driven state for chat and contacts with smooth UI updates.
  • Standalone Components: Fully modular architecture for independent testing.
  • Tailwind CSS: Custom design tokens provide unified theming.
// Signal-Driven State Management export class ChatComponent { chatContacts = signal<ChatContactDTO[]>([]); selectedUser = signal<ChatContactDTO | null>(null); selectUser(user: ChatContactDTO) { this.selectedUser.set(user); } }

5.2 Robust Backend Services

Structured Spring Boot (Java 17) backend powers the platform.

Database: Relational JPA for financial and schedule integrity.

WebSockets: STOMP/SockJS for bidirectional messaging.

Security: Stateless authentication protecting user privacy.
